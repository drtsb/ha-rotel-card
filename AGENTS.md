# AGENTS.md — Руководство для AI-ассистентов

## Описание проекта

Этот репозиторий содержит кастомную Lovelace-карточку для интеграции усилителей Rotel с Home Assistant через интеграцию [`ha-rotel`](https://github.com/). Карточка реализована на **TypeScript + Lit/LitElement**, собирается в единый автономный JS-бандл при помощи **Rollup** или **Vite** и предназначена для установки через **HACS** в категории `plugin` (frontend card).

## Критические правила

- **Версионирование.** При ЛЮБЫХ изменениях функционала или UI обязательно инкрементировать версию в `package.json` (semver: `MAJOR.MINOR.PATCH`).
- **Стилистика Hi-Fi.** Карточка должна сохранять минималистичную эстетику Hi-Fi аудиоаппаратуры. Акцент на читаемости, аккуратных контролах и сдержанной цветовой палитре.
- **Диапазон громкости.** Шкала громкости — **0–96** (условные единицы, принятые в Rotel). 
- **Fixed Volume / Pass-Through.** При активном режиме `Fixed Volume` / `Pass-Through` ползунок громкости должен динамически отключаться и блокироваться (disabled/readonly визуально). Запрещено отправлять команды изменения громкости в этом состоянии.
- **Отсутствие мерцания.** Оптимизировать рендеринг Lit: подписываться только на изменения релевантных сущностей устройства, минимизировать перерендеры, использовать `requestUpdate` осознанно. Для ползунков применять **дебаунс/троттлинг** чтобы не спамить `media_player`/сервисами HA.
- **Единый бандл.** Сборка должна формировать **один автономный файл** `rotel-card.js` (без внешних CDN-зависимостей), готовый к подключению в Lovelace.
- **Только релевантные обновления.** Не триггерить обновление всей карточки при несущественных изменениях хасс-состояний. Учитывать только сущности, явно указанные в конфигурации + основные сущности Rotel.

## Структура сборки

- Исходники: `src/` (TypeScript, Lit компоненты, стили, типы, утилиты)
- Конфиг сборки: `rollup.config.*` или `vite.config.*`
- Выходной бандл: `rotel-card.js` (в корне репозитория либо в `dist/`, но он должен быть доступен для HACS — см. `.gitignore`)
- Типы: `tsconfig.json`

## Команды разработки

```bash
npm install        # установка зависимостей
npm run build      # production-сборка единый rotel-card.js
npm run watch      # watch-режим для разработки
npm run typecheck  # проверка типов без эмита
npm run lint       # линтинг (если настроен)
```

## Обязательный чеклист перед сдачей задачи

Перед коммитом/отправкой изменений **обязательно** выполнить:

- [ ] **TypeScript:** `npm run typecheck` проходит без ошибок
- [ ] **Сборка:** `npm run build` успешно собирает бандл, результатом является единый автономный `rotel-card.js`
- [ ] **Версия:** версия в `package.json` инкрементирована при любых изменениях UI/функционала
- [ ] **Логика Fixed Volume:** ползунок громкости корректно блокируется при Fixed Volume/Pass-Through, команды не отправляются
- [ ] **Производительность:** нет излишних перерендеров, нет мерцания, используется подписка только на нужные сущности, ползунки дебаунснуты
- [ ] **Совместимость:** карточка не добавляет внешних скриптов/шрифтов из сети, работает автономно
- [ ] **Конфиг валиден:** типы конфигурации актуализированы, README при необходимости обновлён
